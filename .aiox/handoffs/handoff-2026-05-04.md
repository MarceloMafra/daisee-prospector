## 🎓 Aprendizados & Patterns

### Pattern: Edição Inline
```
Estado: editingX, XInput, savingX
Função helper: saveField(field, value, setEditing, setSaving)
Fluxo:
1. User clica "Editar"
2. Input aparece com estado editingX=true
3. User digita e clica "Salvar"
4. Chamada API PUT
5. Refresh de dados
6. Close editor
```

### Integração Claude
- Modelo: `claude-opus-4-6` (melhor qualidade)
- Max tokens: 2000
