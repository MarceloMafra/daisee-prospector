## 🎯 COMO USAR ESTE KIT

### Cenário 1: Você é um SDR (Sales Development Rep)

**Seu fluxo:**
1. Leia `DAISEE_Quick_Reference.md` (5 min)
2. Receba nome + LinkedIn do prospect
3. Identifique setor + cargo
4. Vá para `DAISEE_Sales_Knowledge_Base.md` e procure [SETOR]
5. Entenda as dores + argumentos específicos
6. Escolha 1 prompt de email em `DAISEE_Prompt_Templates.md`
7. Preencha [NOME], [CARGO], [EMPRESA], [SETOR], [GATILHO]
8. Copie o prompt e cole em Claude.ai
9. Claude gera email personalizado
10. Copie o resultado e envie

**Tempo total:** 10-15 minutos/prospect

---

### Cenário 2: Você é um AE (Account Executive) preparando reunião

**Seu fluxo:**
1. Prospect aceitou reunião
2. Leia `DAISEE_Sector_Comparison_Matrix.md` para entender o setor
3. Vá para `DAISEE_Sales_Knowledge_Base.md` e procure [SETOR]
4. Identifique: dores + argumentos + soluções específicas
5. Escolha 1 prompt de argumentação em `DAISEE_Prompt_Templates.md` (#6, #7, #14)
6. Preencha com dados do prospect
7. Copie para Claude.ai
8. Claude gera script de 30 minutos
9. Imprima/revise o script
10. Leve `DAISEE_Quick_Reference.md` impressa como backup

**Tempo total:** 20-30 minutos de preparação

---

### Cenário 3: Você está treinando um novo vendedor

**Seu fluxo:**
1. Imprima `DAISEE_Quick_Reference.md` (1 página)
2. Dê ao vendedor novo para revisar (5 min)
3. Explique os 5 setores + ICPs (10 min)
4. Faça um "jogo de role-play":
   - Dê nome + LinkedIn de um prospect fictício
   - Vendedor identifica setor + cargo
   - Vendedor cria email usando template + Claude
   - Você revisa e dá feedback
5. Depois, use `DAISEE_Sector_Comparison_Matrix.md` para reunião 1:1 semanal

**Tempo total:** 1-2 horas de onboarding inicial

---

### Cenário 4: Você está criando conteúdo (blog, guide, webinar)

**Seu fluxo:**
1. Leia `DAISEE_Sales_Knowledge_Base.md` na íntegra
2. Escolha um setor para focar
3. Copie um prompt de template (#9, #10, #11, #12)
4. Preencha com dados do setor
5. Cole em Claude.ai
6. Claude gera conteúdo (deck, case study, artigo)
7. Revise, refine e publique

**Exemplos de conteúdo possível:**
- Blog post: "Por que Farmacêuticas Perdem Tempo em Buscas de POPs"
- Webinar: "Compliance em Varejo: Como 500 Lojas Ficam Alinhadas"
- Case study: "[Nome Empresa] Reduziu o Tempo de Busca"
- Slide deck: "5 Problemas que DAISEE Resolve em [SETOR]"
