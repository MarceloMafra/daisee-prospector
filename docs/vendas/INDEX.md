## 📖 COMO NAVEGAR

### Cenário 1: "Tenho 5 minutos"
1. Leia `DAISEE_Quick_Reference.md`
2. Identifique o setor do prospect
3. Use os filtros LinkedIn para buscar

### Cenário 2: "Tenho 15 minutos"
1. Leia `DAISEE_Sector_Cheat_Sheet.md` (seu setor)
2. Escolha seu argumento
3. Vá para `DAISEE_Prompt_Templates.md`

### Cenário 3: "Tenho 30 minutos"
1. Leia `DAISEE_Sales_Knowledge_Base.md` (seu setor)
2. Entenda as dores + argumentos
3. Use `DAISEE_Prompt_Templates.md` para gerar conteúdo com Claude

### Cenário 4: "Vou prospetar hoje"
1. Comece com `README_SALES_KIT.md` (10 min)
2. Leia seu setor em Knowledge Base (15 min)
3. Escolha template em Prompt Templates
4. Use Claude para gerar email
5. Prospeque!
